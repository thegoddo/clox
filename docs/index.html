clox — project docs

A refresher for coming back to the project after a long break. Updated for chapter 20 (commit 1f47560).

Short version It's a Lox bytecode interpreter in C (Crafting Interpreters, Part III). You've finished chapter 20 (Hash Tables). It still evaluates single expressions only (numbers, booleans, nil, strings, + concatenation, comparisons), but every string is now interned in a hash table (vm.strings), so string equality is a pointer compare. The new Table in table.c is ready to hold global variables in chapter 21. It builds cleanly with gcc and passes the smoke tests.

When you return

  1. Build: export PATH=/c/msys64/ucrt64/bin:$PATH then gcc -Wall -Wextra -std=c11 *.c -o clox (make also needs clang-format).
  2. Try 1 + 2 * 3, "st" + "ri" + "ng", "a" + "b" == "ab", "a" + 1 (runtime error).
  3. Optional tidy-up: install clang-format and run make format — the chapter-20 code was committed unformatted because the pre-commit hook isn't enabled (git config core.hooksPath .githooks).
  4. Begin chapter 21 (Global Variables): statements, print, var, and a vm.globals table.
