debug.c

Disassembler: bytecode → text.

Support73 linesincludes: stdint.h, stdio.h, chunk.h, debug.h, value.h

What it does

Walks the byte array. Each line is offset, line number (or | if same as the previous instruction), then the opcode name and, for OP_CONSTANT, the pool index and the constant's value. Two helpers do the formatting: simpleInstruction (1 byte) and constantInstruction (2 bytes).

== code ==
0000    1 OP_CONSTANT         0 '1'
0002    | OP_CONSTANT         1 '2'
0004    | OP_ADD
0005    | OP_RETURN

What's in it

SymbolMeaning
disassembleChunkLoop calling disassembleInstruction.
disassembleInstructionBig switch over opcode.
simpleInstruction / constantInstructionstatic helpers.

Things to remember

  • Every new opcode must be added to the switch here or it prints Unknown opcode N. All 14 current ones are present.
