Makefile

Build, format, check-format, clean.

Tooling28 lines

What it does

Plain GNU make with gcc, -Wall -Wextra -std=c11. Everything is compiled in one command (no object files).

TargetDoes
make / allformat then build
buildProduce ./clox (rebuilds if any source/header changed)
formatclang-format -i on all sources + headers
check-formatDry-run; fails if anything would change (what the hook runs per-file)
cleanrm -f clox

Things to remember

  • Add new files in both SOURCES and HEADERS or they won't link / won't trigger rebuilds.
  • Needs gcc and clang-format on PATH. gcc lives in C:msys64Crt64in (not on the Git-Bash PATH by default: export PATH=/c/msys64/ucrt64/bin:$PATH); clang-format was not found anywhere, so make (which formats first) will fail until it is installed.
