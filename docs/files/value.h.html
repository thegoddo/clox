value.h

The Value type: tagged union (bool / nil / number / heap object) + dynamic ValueArray.

Data47 linesincludes: common.h
used by: vm.h, vm.c, chunk.h, chunk.c, value.c, debug.c

What it does

Defines what a runtime value is. A Value is a 16-byte struct: a ValueType tag plus a union holding a bool, a double or an Obj* (heap object, e.g. a string; see object.h). Macros wrap construction (*_VAL), type tests (IS_*) and unwrapping (AS_*). ValueArray is the growable array used for a chunk's constant pool.
