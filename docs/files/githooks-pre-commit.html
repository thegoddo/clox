.githooks/pre-commit

Git hook: refuse commits with unformatted C.

Tooling23 lines

What it does

Lists staged .c/.h files and runs clang-format --dry-run --Werror on each; exits 1 with a hint to run make format if any need changes.

Things to remember

  • This is why commit f5c8ffd is titled “format before commit”.

Issues found while reading

SevLineProblem
bug—Git only runs it if core.hooksPath points here. In this clone git config core.hooksPath is empty, so the hook is currently inactive. Activate with git config core.hooksPath .githooks.
nit22The exit 1 sits inside a pipe's subshell (printf | while). Under set -e the pipeline status still propagates, so it works in practice, but it's subtle.
