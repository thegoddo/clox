main.c

CLI: REPL when no args, run a script file when one arg.

Entry77 linesincludes: vm.h, stddef.h, stdio.h, stdlib.h, string.h

What it does

main → initVM() → one of three modes → freeVM(). repl() reads up to 1023 chars per line and calls interpret (errors don't end the loop). runFile() reads the whole file into a malloc'd buffer, interprets, frees it, and exits with a status mapped from InterpretResult. Anything else prints usage.

Exit codeMeaning
64Bad usage (too many args)
65Compile error
70Runtime error
74I/O error (can't open/read file, OOM)

What's in it

SymbolMeaning
main(argc, argv)Dispatcher.

readFile(path)Slurp file to NUL-terminated buffer.

Things to remember

  • Codes follow BSD sysexits.h conventions, as in the book.
  • A line longer than 1023 chars in the REPL would be split into two inputs.

21static char *readFile(const char *path) {
22 FILE *file = fopen(path, "rb");
23
24 if (file == NULL) {
25 fprintf(stderr, "Could not open file \"%s\".\n", path);
26 exit(74);
27 }
28
29 fseek(file, 0L, SEEK_END); // open the file and go to the end
30 size_t fileSize =
31 ftell(file); // ftell will calculate the pointer from the start till the
32 // pointer, in our case the 'end'
33 rewind(file); // go back to start
34
35 char *buffer = (char *)malloc(fileSize + 1);
36 if (buffer == NULL) {
37 fprintf(stderr, "Not enough memory to read \"%s\".\n", path);
38 exit(74);
39 }
40 size_t bytesRead = fread(buffer, sizeof(char), fileSize, file);
41 if (bytesRead < fileSize) {
42 fprintf(stderr, "Could not read file \"%s\".\n", path);
43 exit(74);
44 }
45 buffer[bytesRead] = '\0';
46
47 fclose(file);
48 return buffer;
49}

51static void runFile(const char *path) {

58 if (result == INTERPRET_RUNTIME_ERROR)
