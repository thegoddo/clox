memory.c

Implements reallocate() and freeObjects().

Support38 linesincludes: stdlib.h, memory.h

What it does

One function. newSize == 0 → free and return NULL; otherwise realloc, and exit(1) if the OS says no (no message printed).

What's in it

SymbolMeaning
void *reallocate(void*, size_t oldSize, size_t newSize)Grow / shrink / free in one call.

Things to remember

  • oldSize is unused today — it's there for the future GC byte accounting. With -Wextra gcc will warn about the unused parameter.

Chapter 19 additions

freeObject(Obj*) (static) switches on the object type and frees an ObjString plus its character buffer. freeObjects() walks vm.objects and is called from freeVM(). Note the case OBJ_STRING: body is wrapped in braces because it declares a variable.
