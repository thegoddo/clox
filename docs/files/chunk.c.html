chunk.c

Chunk lifecycle: init, free, write a byte, add a constant.

Data40 linesincludes: stdint.h, sys/types.h, chunk.h, memory.h, value.h

What it does

writeChunk grows code and lines together when full, then stores the byte and its line. addConstant appends to the pool and returns its index — the compiler puts that index in the byte after OP_CONSTANT, which is why a chunk can hold at most 256 constants.

What's in it

SymbolMeaning
initChunk(c)Zero the struct, init the pool.
freeChunk(c)Free code, lines, pool, then re-init.
writeChunk(c, byte, line)Append one byte.
addConstant(c, v)Returns index of the new constant.

Things to remember

  • freeChunk ends with initChunk so a freed chunk is safe to reuse/free again.
