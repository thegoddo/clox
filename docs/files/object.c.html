object.c

Allocates heap objects and strings (copyString / takeString); printObject.

Data46 linesincludes: stddef.h, stdio.h, string.h, memory.h, object.h, value.h, vm.h

What it does

Creates objects. allocateObject asks reallocate for size bytes, sets the type tag, and pushes the new object onto the head of vm.objects. allocateString wraps that for ObjString. copyString duplicates a character range (adding the NUL) — used for literals, since the source text is freed after compiling. takeString adopts a buffer the caller already allocated — used by concatenation, avoiding a second copy.

Things to remember

  • Order matters: allocateString is static and has no prototype, so it must be defined above its callers.
  • Nothing is interned yet, so "a" == "a" relies on content comparison in valuesEqual (chapter 20 changes that).
