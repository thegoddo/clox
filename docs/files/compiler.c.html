compiler.c

Single-pass Pratt parser that emits bytecode directly (no AST).

Front-end290 linesincludes: stdint.h, stdio.h, stdlib.h, sys/types.h, chunk.h, common.h, compiler.h, debug.h, scanner.h

What it does

The heart of the front-end. Two globals: parser (current/previous token, hadError, panicMode) and compilingChunk. Parsing is driven by rules[] — a table indexed by TokenType giving each token an optional prefix function, optional infix function, and a precedence. parsePrecedence(p) consumes one token, runs its prefix rule, then keeps folding infix operators while their precedence is ≥ p. Each parse function emits bytecode as it goes, so the output is postfix order — exactly what a stack VM wants.

Today the grammar is one expression: numbers, true/false/nil, grouping, unary - !, binary + - * / == != < <= > >=. No statements, variables, strings or control flow.

Things to remember

  • binary() parses its right operand at precedence + 1 — that is what makes operators left-associative.
  • Desugaring: a != b → EQUAL NOT; a >= b → LESS NOT; a <= b → GREATER NOT. (Technically wrong for NaN, as the book notes.)
  • compile(): initScanner → advance → expression → consume(EOF) → endCompiler.

Chapter 19 additions

string() is the prefix rule for TOKEN_STRING: it copies the lexeme without its quotes via copyString and emits it as a constant.

267static void parsePrecedence(Precedence precedence) {
268 advance();
269 ParseFn prefixRule = getRule(parser.previous.type)->prefix;
270 if (prefixRule == NULL) {
271 error("Expect expression.");
272 return;
273 }
274
275 prefixRule();
276
277 while (precedence <= getRule(parser.current.type)->precedence) {
278 advance();
279 ParseFn infixRule = getRule(parser.previous.type)->infix;
280 infixRule();
281 }
282}

286bool compile(const char *source, Chunk *chunk) {
287 initScanner(source);
288 compilingChunk = chunk;
289
290 parser.hadError = false;
291 parser.panicMode = false;
292 advance();
293 expression();
294 consume(TOKEN_EOF, "Expect end of expression.");
295 endCompiler();
296 return !parser.hadError;
