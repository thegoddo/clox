table.h

Hash table types (Entry, Table) and the table API.

Data27 linesincludes: common.h, value.h
used by: object.c, table.c, vm.c, vm.h

What it does

Declares the hash table used for string interning now and for global variables, fields and methods later. Keys are always ObjString* (interned, so key identity is pointer identity); values are any Value.

What's in it

SymbolMeaning
Entry{ ObjString *key; Value value; } — one bucket.
Table{ int count; int capacity; Entry *entries; } — count includes tombstones.
initTable / freeTableLifecycle.
tableSet(t, key, v)Insert or overwrite; returns true if the key was new.
tableGet(t, key, &out)Lookup; returns false if absent.
tableDelete(t, key)Leaves a tombstone; returns false if absent.
tableAddAll(from, to)Copy every live entry (used later for inheritance).
tableFindString(t, chars, len, hash)Find an interned string by content — the one lookup that compares characters.

Things to remember

  • ObjString comes from the forward declaration in value.h; uint32_t comes via common.h.
