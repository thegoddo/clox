vm.h

VM state, result codes, public API.

Runtime28 linesincludes: chunk.h, value.h, stdint.h
used by: main.c, vm.c, compiler.h

What it does

VM holds the chunk being run, the instruction pointer ip, and a fixed 256-slot value stack with stackTop pointing one past the top element. InterpretResult = OK / COMPILE_ERROR / RUNTIME_ERROR — main.c maps those to exit codes.
