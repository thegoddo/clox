value.c

ValueArray growth/free, printValue, valuesEqual.

Data56 linesincludes: stdio.h, memory.h, value.h

What it does

The constant pool plumbing and the two per-type operations. printValue uses %g for numbers (so 3.0 prints as 3). valuesEqual first compares tags — different types are never equal, there is no implicit coercion — then compares payloads (nil is always equal to nil).

What's in it

SymbolMeaning
initValueArray(arr)Zero everything.
writeValueArray(arr, v)Append, growing via GROW_ARRAY if full.
freeValueArray(arr)Free storage and reset.
printValue(v)Print without newline.
valuesEqual(a, b)Strict equality; used by OP_EQUAL.

Things to remember

  • The pattern here — count / capacity / pointer, grow ×2 — is identical to Chunk; that duplication is by design in the book.
