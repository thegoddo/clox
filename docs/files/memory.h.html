memory.h

Dynamic-array growth macros and the single allocation entry point.

Support17 linesincludes: common.h
used by: chunk.c, value.c, memory.c

What it does

All heap growth/shrink goes through reallocate(). The macros are thin typed wrappers so call sites don't compute sizeof by hand.

What's in it

SymbolMeaning
GROW_CAPACITY(c)0 → 8, then doubles (8, 16, 32…).
GROW_ARRAY(type, ptr, old, new)Typed reallocate of old → new elements; casts the result to type *.
FREE_ARRAY(type, ptr, old)reallocate(ptr, sizeof(type)*old, 0) – frees and returns NULL (result is discarded).
reallocate(ptr, oldSize, newSize)Implemented in memory.c.

Things to remember

  • Having a single choke point is what will later let the GC track bytes allocated (chapter 26).
