scanner.c

On-demand lexer: characters → tokens.

Front-end238 linesincludes: stdbool.h, string.h, scanner.h

What it does

A single global Scanner { start, current, line }. scanToken() skips whitespace/comments, marks the token start, reads one character and dispatches: letters → identifier(), digits → number(), " → string(), punctuation → direct or via match() for two-char operators. Keywords are recognised with a hand-written trie (identifierType switches on the first letter, then checkKeyword compares the rest with memcmp) — no hash table, no allocation.

What's in it

SymbolMeaning
initScanner / scanTokenPublic.
isAlpha, isDigit, isAtEnd, advance, peek, peekNext, matchCursor helpers.

identifier / number / stringMulti-character token readers.

Things to remember

  • Strings are scanned (token includes quotes, newlines inside bump line) but the compiler has no rule for TOKEN_STRING yet.
  • Numbers: digits, optionally . followed by at least one digit. No leading . or trailing ..

69static void skipWhitespace() {
