common.h

Umbrella header: standard includes + debug switches.

Support10 linesincludes: stdbool.h, stddef.h, stdint.h
used by: vm.c, compiler.c, chunk.h, value.h, memory.h

What it does

Every other header pulls this in (directly or transitively) so bool, size_t and uint8_t are always available. It is also the single place where the two compile-time debug switches live.

What's in it

SymbolMeaning
DEBUG_PRINT_CODEIf defined, endCompiler() disassembles the finished chunk to stdout (compiler.c:120).
DEBUG_TRACE_EXECUTIONIf defined, the VM is meant to dump the stack + current instruction before every step. The guard in vm.c was inverted and has been fixed.

Things to remember

  • Both switches are defined unconditionally, so every build is a debug build. Comment them out (or move to -D flags in the Makefile) for quiet output.
