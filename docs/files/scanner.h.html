scanner.h

Token types and the scanner's public API.

Front-end63 lines
used by: compiler.c, scanner.c

What it does

Defines TokenType (40 kinds: punctuation, one/two-char operators, literals, keywords, plus TOKEN_ERROR and TOKEN_EOF) and Token — a view into the source (start pointer + length), not a copy — with its line number.

What's in it

SymbolMeaning
TokenTypeOrder matters: compiler.c's rules[] table is indexed by it.
Token{ type, start, length, line }
initScanner(source)Point the scanner at a NUL-terminated string.
scanToken()Return the next token on demand.

Things to remember

  • Because tokens point into the source buffer, the source must outlive compilation (true: main.c frees it only after interpret returns).
