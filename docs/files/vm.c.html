vm.c

Bytecode interpreter: run loop, stack, runtime errors.

Runtime152 linesincludes: vm.h, chunk.h, common.h, compiler.h, value.h, stdarg.h, stddef.h, stdio.h

What it does

One global VM vm. interpret() makes a local Chunk, hands it to compile(), then points vm.ip at the first byte and runs run() — a for(;;) switch dispatch loop. Operands live on the stack. BINARY_OP type-checks both operands are numbers, pops two, pushes the result (numbers for arithmetic, bools for >/<). OP_NOT uses isFalsey (only nil and false are falsey). OP_RETURN pops and prints the final value — a temporary stand-in so the REPL shows results.

Runtime errors print the message plus [line N] in script (found via lines[ip - code - 1]) and reset the stack.

Things to remember

  • There is no default: in the opcode switch — an unknown opcode silently loops. Acceptable while the compiler is the only producer.
