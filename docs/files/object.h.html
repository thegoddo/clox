object.h

Heap-object header: Obj, ObjType, ObjString and the IS_/AS_ macros.

Data38 linesincludes: common.h, value.h

What it does

Defines the heap half of a Value. Every heap object begins with an Obj header (a type tag plus a next pointer that threads all objects into one list owned by the VM, so freeObjects() can find them). ObjString embeds Obj as its first field, so an ObjString* can be cast to Obj* and back (C's struct-inheritance trick).

What's in it

SymbolMeaning
ObjTypeEnum of object kinds. Only OBJ_STRING so far.
struct ObjHeader: type, next (intrusive linked list).
struct ObjStringObj obj; int length; char *chars; — chars are NUL-terminated and heap-owned.
OBJ_TYPE / IS_STRING / AS_STRING / AS_CSTRINGTag read, type test, cast to ObjString*, cast to char*.
isObjType()Static inline instead of a macro because IS_STRING would otherwise evaluate its argument twice.
copyString / takeStringMake a string from a borrowed buffer (copies) or from an owned buffer (takes it).

Things to remember

  • struct Obj / struct ObjString are forward-declared in value.h (as Obj / ObjString) to break the include cycle with Value.
  • The string and its characters are two separate allocations (the book's later challenge turns this into a flexible array member).
