.clang-format

Formatter config (LLVM-style dump, 2-space indent).

Tooling321 lines

What it does

A full clang-format --dump-config style file (321 lines). The settings that matter day to day:

  • IndentWidth: 2, UseTab: Never
  • ColumnLimit: 80
  • BreakBeforeBraces: Attach (K&R)
  • PointerAlignment: Right (Chunk *chunk)

Things to remember

  • Don't hand-edit unless you want to change the style; it's the dump of a base style.
