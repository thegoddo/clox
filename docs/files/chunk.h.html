Bytecode container: opcodes + Chunk struct.

What it does

A Chunk is one compiled unit: a byte array of instructions, a parallel array of source line numbers (one int per byte, for error messages), and a constant pool (ValueArray). The OpCode enum is the instruction set — see the opcode table in the LLD.

What's in it

SymbolMeaning
OpCode14 opcodes: CONSTANT, NIL, TRUE, FALSE, EQUAL, GREATER, LESS, ADD, SUBTRACT, MULTIPLY, DIVIDE, NOT, NEGATE, RETURN.
Chunk{ count, capacity, uint8_t *code, int *lines, ValueArray constants }
initChunk / freeChunk / writeChunk / addConstantImplemented in chunk.c.

Things to remember

  • lines[i] belongs to code[i] — simple but wasteful (4 bytes of line per 1 byte of code). Run-length encoding is one of the book's challenges.
