1. Memory & dynamic arrays

Three structures share one growth pattern: Chunk.code / Chunk.lines, and ValueArray.values. Each has count (used) and capacity (allocated).

append(x):
  if capacity < count + 1:
      capacity = (capacity < 8) ? 8 : capacity * 2     // GROW_CAPACITY
      ptr = reallocate(ptr, sizeof(T)*old, sizeof(T)*capacity)
  ptr[count++] = x

reallocate(ptr, old, new) → new == 0: free, return NULL. Else realloc; NULL result ⇒ exit(1). Amortised O(1) append. oldSize is unused for now (GC accounting later). See memory.h and memory.c.

3. Chunk layout & constant encoding

Chunk
 ├─ code[]     uint8_t   [OP_CONSTANT][ 0 ][OP_CONSTANT][ 1 ][OP_ADD][OP_RETURN]
 ├─ lines[]    int       [   1       ][ 1 ][   1       ][ 1 ][  1   ][   1     ]   one per byte
 └─ constants  Value[]   [ 1 ][ 2 ]
  • Operand is a single byte ⇒ max 256 constants per chunk; makeConstant reports Too many constants in one chunk. beyond that (compiler.c:106).
  • lines is parallel to code; the VM looks up lines[ip - code - 1] for runtime errors, the disassembler prints it per instruction.
  • Constants are never de-duplicated: 1 + 1 stores two constants.

Keyword trie

6. Compiler (Pratt parser)

Chunk *compilingChunk;                                          // output target

Precedence ladder (low → high)

NONE → ASSIGNMENT → OR → AND → EQUALITY → COMPARISON → TERM → FACTOR → UNARY → CALL → PRIMARY

Algorithm

parsePrecedence(p):
  advance()
  prefix = rules[previous.type].prefix        // none ⇒ error "Expect expression."
  prefix()
  while p <= rules[current.type].precedence:
      advance()
      rules[previous.type].infix()

binary():   op = previous.type
            parsePrecedence(rules[op].precedence + 1)   // +1 ⇒ left-assoc
            emit op bytes
unary():    op = previous.type;  parsePrecedence(PREC_UNARY);  emit NEGATE/NOT

Errors

errorAt prints [line N] Error at 'lexeme': msg (or at end), sets hadError. Scanner error tokens are reported by advance() and skipped. panicMode is set on the first error so later errors are suppressed; there is no synchronize() yet (book chapter 21).

7. Virtual machine

VM { Chunk *chunk;  uint8_t *ip;  Value stack[256];  Value *stackTop; }   // global `vm`

   stack[0]  stack[1]  stack[2] ...        stackTop → first free slot
   push: *top++ = v        pop: return *--top        peek(d): top[-1-d]

run() loop

for (;;) {
  [if tracing: print stack contents + disassemble instruction at ip]   // enabled by DEBUG_TRACE_EXECUTION
  switch (instruction = *ip++) {
    CONSTANT: push(constants[*ip++])
    NIL/TRUE/FALSE: push literal
    EQUAL: b=pop a=pop push(valuesEqual)
    GREATER/LESS/ADD/SUB/MUL/DIV: BINARY_OP (type-check → pop b, pop a → push(a op b))
    NOT: push(isFalsey(pop))     NEGATE: check number; push(-pop)
    RETURN: print(pop); return OK
  }
}
Runtime errorRaised by
Operands must be numbers.BINARY_OP (add, sub, mul, div, >, <)
Operand must be a number.OP_NEGATE

After printing the message and [line N] in script, the stack is reset and run returns INTERPRET_RUNTIME_ERROR.

No overflow check: pushing past 256 values corrupts memory. Not reachable with the current single-expression grammar, but reachable later.

8. Disassembler format

== code ==
0000    1 OP_CONSTANT         0 '1'     offset | line | name | const-index | value
0002    | OP_CONSTANT         1 '2'     "|" ⇒ same source line as previous instruction
0004    | OP_ADD
0005    | OP_RETURN

disassembleInstruction returns the next offset (1 for simple, 2 for constant instructions). Add each new opcode to its switch.
